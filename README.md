# 📊 HR Analytics Command Dashboard

An interactive **HR Analytics Dashboard** built with **Microsoft Power BI** to transform workforce data into clear, actionable insights for HR teams and decision-makers.

The dashboard provides a centralized view of **headcount, attrition, demographics, departmental turnover, employee performance, contracts, and compensation**.

## 📌 Project Overview

Human Resources teams generate large amounts of employee data, but turning that data into useful workforce insights can be challenging.

This project was developed to create an **executive-friendly HR analytics solution** that makes it easier to monitor workforce trends, identify turnover patterns, and understand employee demographics and performance.

The dashboard combines multiple HR metrics into a single interactive reporting environment.

## 🔍 Key Analysis Areas

### 🏢 Departmental Turnover
Analyzes former employees across different business units to highlight areas experiencing higher employee turnover.

### 👥 Employee Demographics
Examines gender distribution across different age groups to provide insight into workforce composition.

### ⭐ Performance Analysis
Shows the distribution of employee performance ratings across different job roles.

### 📄 Contract & Attrition Analysis
Analyzes employee departures by contract type, including:

- Permanent
- Fixed-term
- Contractor / Gig
- Intern

### 💼 Workforce Structure
Provides visibility into employee headcount by contract type and work arrangement.

### 🎓 Education-Level Analysis
The dashboard includes interactive filtering for employee education levels:

- Bachelor's
- Diploma
- Master's
- PhD / Professional
- Secondary

## 💡 Business Questions

The dashboard helps answer important HR questions such as:

- How large is the organization's workforce?
- How many employees are currently active?
- What is the current employee attrition rate?
- Which departments have experienced the highest turnover?
- How is the workforce distributed by gender and age?
- How are performance ratings distributed across job roles?
- Which contract types experience higher employee attrition?
- What is the current workforce structure?
- What is the average employee salary?
